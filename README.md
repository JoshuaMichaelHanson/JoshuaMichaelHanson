## 🦀 Rusty Zipper

### [github.com/JoshuaMichaelHanson/rusty-zipper-v1](https://github.com/JoshuaMichaelHanson/rusty-zipper-v1)

A Rust CLI + TUI archive utility.

It started because I was tired of manually extracting piles of student assignment archives while grading.

Naturally, the solution was to build an entire tool.

```bash
$ rusty-zipper-1 --cli

Scanning archives...
Extracting...
Done.

# repetitive clicking successfully deleted from workflow
```

Supports command-line automation, an interactive terminal UI, batch operations, and multiple archive formats.

**Built with:** `Rust` • `CLI` • `TUI` • `Automation`

# 🤖 Human + AI Development

I'm especially interested in how software engineering changes when AI becomes another tool in the development environment.

Not just:

```text
"write this function"
```

but:

```text
idea
  ↓
requirements
  ↓
agent plan
  ↓
implementation
  ↓
tests
  ↓
review
  ↓
iterate
  ↓
ship
```

I'm experimenting with coding agents, persistent agent memory, structured project instructions, automated workflows, and ways to keep the **engineer in control while letting the machines do more of the mechanical work.**
